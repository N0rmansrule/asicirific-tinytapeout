# ASICirific — bit-serial RV32E microcontroller for TinyTapeout

A small RISC-V microcontroller: a bit-serial RV32E CPU, a QSPI controller for
external flash and PSRAM, and GPIO for buttons and sensors. No on-chip RAM; the
program lives on an external flash chip flashed over USB-C via the demo board.

See docs/info.md for the architecture, pin map, and how to program it.
